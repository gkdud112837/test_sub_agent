> 쓰는 사람: 금요일 저녁, 어두운 야시장 입구나 매대 앞에서 한 손으로 휴대폰을 보는 방문객 (spec/시나리오.md 장면 2 · 4)
> 바뀐 이유: 사용자 요청 "로컬 야시장 느낌 · 어두운 밤에 반짝반짝 · 중간중간 포차 디자인 · 폰 프레임 제거" (decision_log D-12 · D-13)

## 1. 원칙

| # | 원칙 | 화면에서의 뜻 |
|---|---|---|
| 1 | **밤에 켜진 불빛만 빛난다** | 바탕은 어두운 밤하늘. 빛(글로)은 "지금 되는 것"에만: 영업 중 매대 · 결제 가능 칸 · 선택한 버튼 |
| 2 | **포차 골목을 걷는 느낌** | 줄조명 → 네온 간판 → 칠판 → 천막 차양 아래 포차들. 위에서 아래로 골목에 들어가는 순서 |
| 3 | **줄 서기 전 3초** | 장식이 많아도 결제 칸 4개(현금 · 카드 · 이체 · 페이)는 모든 매대에서 같은 자리 · 같은 순서 |
| 4 | **확정 · 미확인을 모양으로** | 가능 = 민트 네온 ✓, 불가 = 꺼진 글자 취소선, 미확인 = 점선 ? |
| 5 | **프레임 없는 모바일** | 휴대폰 목업 없이 화면 그대로. 넓은 화면에서는 480px 폭으로 가운데 정렬 |

## 2. 색 토큰 (어두운 단일 테마 — 의도적)

밤 야시장이 주제라 밝은 테마를 두지 않는다. 휴대폰 설정과 관계없이 늘 어둡다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sky-0` | `#07060F` | 밤하늘 바탕 (위는 보라 `#2B1A4F`, 아래는 숯불 `#3A170F` 번짐) |
| `--surface` / `--surface-2` | `#1A1325` / `#241A31` | 간판 판 · 포차 카드 |
| `--line` | `#3B2D4A` | 테두리 · 점선 구분 |
| `--ink` / `--ink-2` / `--ink-3` | `#FFF3E2` / `#DCCAB6` / `#A592A9` | 본문 · 보조 · 캡션 (따뜻한 흰색) |
| `--bulb` / `--bulb-hot` | `#FFD27A` / `#FFF2CC` | 꼬마전구 · 선택된 버튼 · 주 버튼 |
| `--glow` | `rgba(255,184,77,.55)` | 전구 빛 번짐 |
| `--tarp-r` / `--tarp-o` / `--tarp-w` | `#D8382A` / `#F2842B` / `#F4E3C8` | 포차 천막 (빨강 · 주황 · 크림 줄무늬) · 홍등 |
| `--mint` / `--mint-bg` | `#4FF0B6` / 13% | **가능 · 영업 중** 네온 |
| `--pink` / `--pink-bg` | `#FF5E7C` / 14% | **품절 · 휴무 · 쉬는 날** 네온 |
| `--off` | `#6E6280` | **불가 · 꺼진 불** |
| `--chalk` / `--wood` | `#15241F` / `#5A3B22` | 칠판 · 나무 테두리 |

규칙
- 민트 = 된다, 핑크 = 안 된다, 꺼진 보라 회색 = 없다. 이 세 색은 상태에만 쓴다.
- 색만으로 말하지 않는다: 늘 ✓ · 취소선 · 점선 · 글자를 함께.
- 천막 빨강 · 주황은 장식(차양 · 홍등)에만. 상태 표시에 쓰지 않는다.

## 3. 글꼴

| 역할 | 글꼴 | 쓰는 곳 |
|---|---|---|
| 네온 간판 | **Black Han Sans** | 서비스 이름(네온 글로), 운영 상태 간판, 홍등 번호 |
| 손글씨 | **Nanum Brush Script** | 칠판 "현금 없이 왔어요", "오늘의 포차", 안내 제목 — 포차 손글씨 메뉴판 느낌 |
| 본문 | **Noto Sans KR** 400 · 500 · 700 | 그 밖의 모든 글 |
| 숫자 | **JetBrains Mono** 500 | 개장 · 마감 시각, 입력 시각 |

손글씨는 짧은 제목에만 쓴다 (정보 문장에는 쓰지 않음).

| 이름 | 크기 | 예 |
|---|---|---|
| `neon-title` | 36~48px (화면 폭 비례) | 오늘의 매대판 |
| `brush` | 30~34px | 오늘의 포차 · 현금 없이 왔어요 |
| `sign` | 24px | 영업중 · 쉬는 날 |
| `name` | 17px 700 | 매대 이름 |
| `body` | 15~16px | 문장 |
| `label` | 12~13px | 결제 칸 · 칩 · 출처 |

## 5. 컴포넌트

| 컴포넌트 | 생김새 | 규칙 |
|---|---|---|
| **줄조명** | 화면 맨 위, 두 번 처진 전선에 전구 14개. 전구마다 다른 박자로 깜빡임 | 장식. 화면 읽기에 방해되지 않게 56px 높이 |
| **네온 간판 (제목)** | 크림색 글자 + 주황 · 빨강 빛 번짐. 7초에 한 번 살짝 깜빡 | 페이지에 하나 |
| **운영 상태 간판** | 테두리가 빛나는 네온 박스: `영업중`(민트) · `곧 열어요`(전구색) · `쉬는 날` · `영업 끝`(핑크, 가끔 꺼질 듯 깜빡) | 아래에 진행 막대 · 출처 줄 |
| **칠판** | 짙은 초록 판 + 나무 테두리 + 손글씨 | '현금 없이 왔어요' 스위치 전용 |
| **필터 칩** | 둥근 알약. 선택하면 전구색으로 켜짐 | 넘치면 줄바꿈 |
| **천막 차양** | 빨강 · 크림 줄무늬, 아래 가장자리 물결(스캘럽) | 포차 목록 위, 매대 상세 시트 위 |
| **포차 카드** | 맨 위 주황 미니 차양 + 따뜻한 불빛 번짐. 문 닫은 매대는 차양 · 홍등이 꺼진 회색 | 번호순 |
| **홍등 번호** | 빨간 등 모양 + 위아래 검은 꼭지, 은은하게 숨쉬듯 빛남 | 꺼진 매대는 불 꺼진 등 |
| **결제 칸 4개** ★ | 현금 · 카드 · 이체 · 페이 고정. 가능 = 민트 네온 테두리 ✓ / 불가 = 꺼진 글자 취소선 / 미확인 = 점선 ? | '현금 없이' 켜면 현금 칸 흐리게 |
| **매대 상세 시트** | 위에 천막 차양, 큰 결제 칸 2 × 2, 메뉴(품절 핑크 꼬리표), 출처 "AI 정리 · 상인 입력 hh:mm" | 주 버튼 = 전구색 |
| **토스트** | 전구색 바탕 · 빛 번짐 | 2.4초 |

## 6. 움직임

| 움직임 | 어디 | 길이 |
|---|---|---|
| 깜빡임(twinkle) | 줄조명 전구 · 멀리 번지는 불빛 | 2.4s · 5s 반복 |
| 네온 깜빡(flicker) | 제목 | 7s에 두 번 살짝 |
| 꺼질 듯 깜빡(dying) | 쉬는 날 간판 | 4s에 한 번 |
| 숨쉬기(breathe) | 켜진 홍등 | 3.2s |

- 휴대폰의 "동작 줄이기" 설정이 켜져 있으면 모든 움직임을 끈다.
