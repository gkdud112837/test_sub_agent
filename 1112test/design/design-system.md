## 1. 원칙

| # | 원칙 | 화면에서의 뜻 |
|---|---|---|
| 1 | **줄 서기 전 3초** | 매대 한 줄만 보고 "여기서 살 수 있나"를 판단할 수 있어야 한다. 결제 수단이 제일 먼저 읽힌다 |
| 2 | **확정 · 추정 · 미확인을 섞지 않는다** | 상인이 직접 넣은 값(확정), AI가 정리한 값(출처 표시), 값이 없음(미확인)을 모양으로 구분한다. 없는 값을 채워 넣지 않는다 |
| 3 | **늘 같은 자리** | 결제 수단 4칸은 모든 매대에서 같은 순서 · 같은 위치. 비교는 눈이 아래로만 내려가면 된다 |

## 2. 색 토큰

밝은 테마가 기본, 휴대폰 설정이 어두우면 어두운 테마. **밤 패널**(운영 상태 카드)은 두 테마 모두 남색 바탕이다.

| 토큰 | 밝은 테마 | 어두운 테마 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#F3F4F7` | `#0D1020` | 화면 바탕 |
| `--surface` | `#FFFFFF` | `#161A2C` | 목록 · 시트 |
| `--surface-2` | `#ECEEF3` | `#1F2438` | 칩 · 칸 바탕 |
| `--line` | `#DDE1E8` | `#2A3048` | 구분선 · 테두리 |
| `--ink` | `#141824` | `#EEF0F6` | 본문 |
| `--ink-2` | `#475066` | `#B7BDCD` | 보조 문장 |
| `--ink-3` | `#737C91` | `#858FA6` | 캡션 · 출처 |
| `--night` | `#1C2550` | `#232D63` | 밤 패널 바탕 |
| `--night-ink` | `#F2F4FB` | `#F2F4FB` | 밤 패널 글자 |
| `--night-ink-2` | `#AEB7D6` | `#AEB7D6` | 밤 패널 보조 글자 |
| `--lamp` | `#F2A23C` | `#F4AE52` | 등불 강조 (밤 패널 안 · 브랜드 표시만) |
| `--ok` / `--ok-bg` | `#0B8457` / `#DFF3EA` | `#3CC98F` / `#12301F` | 결제 **가능** · 영업 중 |
| `--off` | `#A3A9B6` | `#5B637C` | 결제 **불가** · 닫음 |
| `--sold` / `--sold-bg` | `#C93838` / `#FCEAEA` | `#FF7A7A` / `#3A1C22` | **품절** · 휴무 · 일찍 닫음 |
| `--focus` | `#2E6BE6` | `#7AA2FF` | 키보드 포커스 · 선택된 컨트롤 |

규칙
- 상태색(ok · off · sold)은 **상태에만** 쓴다. 장식에 쓰지 않는다.
- `--lamp`는 밝은 바탕 위 글자색으로 쓰지 않는다 (대비 부족). 밤 패널 안에서만 글자색.
- 색만으로 상태를 말하지 않는다. 항상 글자(가능 · 불가 · 미확인 · 품절)나 모양(채움 · 취소선 · 점선)을 같이 쓴다.

## 5. 컴포넌트

### 5-1. 밤 패널 (운영 상태)
- 남색 바탕, 상태 한 단어를 간판 글꼴 · 등불색으로 크게: `영업 중` · `개장 전` · `영업 끝` · `쉬는 날`
- 아래 한 줄: 남은 시간 또는 다음 개장 (`금 18:00`)
- 진행 막대: 개장 → 마감 사이 지금 위치
- 출처 줄 (caption): 어떤 자료 기준인지, 공식 공지 연결 여부

### 5-2. 매대 번호패
- 48 × 48px, `--r-m`, `--surface-2` 바탕, 간판 글꼴 숫자 2자리 (`05`)
- 닫은 매대는 투명도 45%

### 5-3. 결제 칸 줄 ★ 이 서비스의 핵심 부품
- 항상 4칸, 항상 같은 순서: **현금 · 카드 · 이체 · 페이**
- 칸 모양으로 상태 구분

| 상태 | 모양 | 글자 |
|---|---|---|
| 가능 | `--ok-bg` 채움, `--ok` 글자, ✓ | 카드 ✓ |
| 불가 | 테두리 없음, `--off` 글자, 취소선 | ~~카드~~ |
| 미확인 | 점선 테두리, `--ink-3` 글자 | 카드 ? |

- '현금 없이 왔어요'를 켜면 현금 칸은 흐리게 (판단에서 빠짐)

### 5-4. 상태 글자
| 상태 | 표시 |
|---|---|
| 영업 중 | `--ok` 점 + "영업 중" |
| 오늘 휴무 | `--sold` 점 + "오늘 휴무" |
| 일찍 닫음 | `--sold` 점 + "일찍 닫음" |
| 입력 전 | `--off` 빈 점 + "입력 전" |
| 야시장 쉬는 날 | `--off` 점 + "쉬는 날" (매대 상태 대신) |

### 5-5. 품절 표시
- 상인이 직접 누른 품절만 표시 (RISK O3)
- 목록: `--sold` 글자 "OO 품절"
- 시트: 메뉴 이름 취소선 + `--sold-bg` 바탕 "품절" 꼬리표

### 5-6. 출처 꼬리표
- caption 크기, `--ink-3`: `AI 정리 · 상인 입력 20:10 · 20분 전`
- 오래된 정보: 앞에 "오래된 정보" 꼬리표

### 5-7. 필터 칩 · 스위치
- 칩: 높이 36px(터치 44px), `--r-s`, 선택 시 `--ink` 바탕 · `--surface` 글자
- 줄이 넘치면 다음 줄로 (가로 스크롤 안 함 — 잘려 보이지 않게)
- 스위치: 52 × 32px, 켜짐 `--ok`

### 5-8. 바텀 시트 · 토스트
- 시트: 위 모서리 24px, 손잡이 막대, 바깥 누르면 닫힘, Esc로 닫힘
- 버튼 높이 52px, 주 버튼은 `--ink` 바탕 (상태색과 겹치지 않게)
- 토스트: 화면 아래 가운데, 2.4초

## 6. 문구 규칙

| 규칙 | 좋은 예 | 피할 예 |
|---|---|---|
| 방문객 말로 | "현금 없이 살 수 있어요" | "결제 수단 필터 적용됨" |
| 없는 건 없다고 | "결제 정보가 아직 없어요" | (빈칸으로 두기 · 추측해 채우기) |
| 누가 고칠지 단정하지 않기 (처리자 미정) | "확인하고 고칠게요" | "상인이 고쳐요" |
| 숫자에는 기준을 | "18:00 개장 · 장사 시간 기준" | "곧 열어요" |

## 7. 쓰지 않는 것
- 이모지 아이콘, 그라데이션 배경, 카드마다 그림자
- 가로 스크롤 칩 줄 (잘려 보임)
- 추정값을 확정값과 같은 모양으로 보여 주기
- 재료에 없는 매대 배치도 · 가격 (decision_log D-06 · D-07)
