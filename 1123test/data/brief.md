# 작업 지시서 (P0 · 메인 세션 작성)

## 목적
SK증권 「IT 하드웨어 2027 연간전망 — IT 인플레이션 다음은?」(첨부 PDF, 13쪽)과 같은 구성으로
**IT 하드웨어 2027 연간전망 리포트**를 쓴다.
구성: 표지 키워드 3개 → 요약 → 2026 리뷰 → 테마 3개 → 쇼티지 부품/기업 선별 → Peer Valuation → Compliance Notice.
독자는 기관·개인 투자자다. 결론은 "불확실한 업황에서 쇼티지가 이어지는 부품/기업을 고르는 기준"으로 끝난다.

## 핵심 질문
- Q1. 2026년 IT 하드웨어 주가는 왜 상반기에 오르고 하반기에 꺾였나?
- Q2. 2027년 세트(스마트폰·PC·TV 등) 출하는 얼마나 역성장하나?
- Q3. LTA(장기공급계약)·증설은 호재인가, 위험인가?
- Q4. IT 인플레이션 이후 CR(Cost Reduction) 압박을 견디는 쇼티지 부품/기업은 어디인가?

## 키워드 3개
1. 디바이스 역성장
2. LTA
3. IT 인플레이션 이후

## 범위
포함
- 세트: 스마트폰, PC·노트북, 태블릿, TV, 폴더블
- 부품: 기판(FCBGA·FCCSP·SLP·HDI·MLB), MLCC, 카메라 모듈·렌즈, 외장재·부자재, RF·전자모듈
- 기간: 2026 리뷰 ~ 2027F
- 지역: 국내 + 대만·일본·중국 Peer

제외
- 반도체 칩·메모리 업황 자체 분석 (원가 변수로만 쓴다)
- 개별 종목 목표주가·투자의견 산정
- 배터리 셀·소재 심층 분석

## 숫자 규칙
- 모든 숫자에 출처와 기준일을 단다. 모르는 값은 지어내지 말고 `[확인필요]`로 쓴다.
- 기준 리포트(첨부 PDF)는 비교 기준이다. 문장을 그대로 옮기지 않는다. 숫자를 쓸 때는 출처를 "SK증권 IT하드웨어 2027 연간전망(비교 기준)"으로 단다.
- 범위 밖이거나 데이터를 구할 수 없으면 `escalations`에 적어 메인 세션에 올린다 (R5).
