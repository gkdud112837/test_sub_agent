## 한 문단 결론

지연을 설명하는 신호는 **해상(선사) 구간의 악천후** 하나입니다. 선사 구간에서 악천후를 만나면 92.6%가 늦지만, 육상 구간과 정상 기상에서는 어디든 약 34%입니다. 선사 5곳의 차이는 오차 범위 안에 있어(p = 0.63) 업체 교체의 근거가 되지 못합니다. 모델(69.0%)도 규칙 하나(69.1%)를 넘지 못합니다. 따라서 바꿀 것은 두 가지입니다. ① 해상 악천후 예보 시 출항 일정을 조정하고 고객에게 미리 알립니다. ② 독일·브라질은 최단 소요일이 39·43일이므로 견적 단계에서 D+60만 받습니다.
