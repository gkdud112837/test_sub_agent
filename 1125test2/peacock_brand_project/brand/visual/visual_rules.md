# 영상 비주얼 규칙 v0.1
상태: 캐릭터 색상은 원본 규격 준용 / 영상 디자인은 승인 전 제안.

## 색상
| 역할 | HEX | 적용 |
|---|---|---|
| 주색 C01 | #B51EAF | 캐릭터 몸통, 브랜드 포인트 |
| 금색 C11 | #EBA22F | 장신구, 장식선 |
| 보석 C12 | #A21BD1 | 보석 포인트 |
| 크림 C02 | #F6D1C6 | 얼굴, 보조색 |
| 핑크 C03 | #FC8EAF | 볼, 부드러운 포인트 |
| 딥 플럼 (신규 제안) | #240923 | 배경, 밝은 화면 텍스트 |
| 아이보리 (신규 제안) | #FFF7F5 | 어두운 화면 텍스트, 배경 |

캐릭터의 C01~C13 전체 색상과 부위 배치는 fixed.md 우선. 영상 배경은 딥 플럼 또는 아이보리, 금색은 얇은 포인트에 한정. 중성광의 캐릭터 고유색을 보존하고 배경 컬러 그레이딩이 본체를 녹색/청색으로 변경하지 않게 한다. SDR Rec.709 납품 제안, sRGB 원본은 적절한 색상 관리 후 변환한다.

## 타이포그래피 (제안)
- 한글 제목: Noto Serif KR SemiBold, 본문/자막: Noto Sans KR Medium.
- 영문 제목: Cormorant Garamond SemiBold, 보조: Noto Sans.
- 1080×1920 기준 제목 76–100px, 본문 44–56px, 보조 32–40px. 2줄 이하, 본문 대비 4.5:1 목표. 폰트 설치 및 라이선스 확인 후 사용.
- 텍스트는 생성 이미지에 직접 넣지 않고 편집 단계에서 합성한다. 확정 로고가 없으면 작업용 명칭을 내부 검수에만 사용한다.

## 영상/모션 (제안)
- 9:16, 1080×1920, 30fps, 15초, H.264 MP4. 플랫폼별 추가 버전은 별도 승인.
- 안전영역: x=108~972, y=220~1530 (플랫폼 UI에 맞춰 재검수). 캐릭터 전신 컷은 머리깃·꼬리·발 잘림 금지, 디테일 컷은 의도적 크롭 허용.
- 소프트 키/필/림, 새틴 펄과 패싯 보석. 과도한 블룸, 랜덤 글리터, 번쩍임 금지.
- 느린 푸시인, 가벼운 패럴랙스, 보석 반사, 한 번의 자연스러운 눈깜빡임. 신체 워핑, 장신구 증식, 좌우 반전 금지.
- 오디오: 섬세한 벨·현악 또는 앰비언트 계열 제안. 상업 이용권 확인, 음성 없이도 이해 가능하게 제작.
