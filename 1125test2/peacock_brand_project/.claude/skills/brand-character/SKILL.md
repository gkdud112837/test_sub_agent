# brand-character

1. `brand/character/fixed.md`와 원본 PNG를 읽고 이미지 생성 도구에 원본을 참조로 제공한다.
2. fixed.md의 영문 고정 프롬프트 및 네거티브 프롬프트를 유지하고 장면·표정만 별도 추가한다.
3. 승인되지 않은 후면·측면·꼬리 접기 요청은 승인 필요로 표시한다. 원본 기반 정지 포즈를 우선한다.
4. 머리깃 3개, 색상 배치, 장신구, 비율, 꼬리 연결, 접지 및 가림을 검수한다.
5. 출력: 장면 ID, 참조 경로, 고정/가변 프롬프트, 모델/seed(가능 시), QA, 승인 상태. 도구 미지원이면 생성 완료라고 말하지 않는다.

공통: 경로는 프로젝트 루트 기준. 확정 사실과 제안을 구분하며 누락된 자료를 임의 생성하지 않는다.
