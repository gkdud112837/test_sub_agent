# brand-visual

1. `brand/visual/visual_rules.md`와 `brand/character/fixed.md`를 읽는다.
2. 매체, 화면비, 길이, 타이포 계층, 안전영역을 명시한다. 사용자 미지정 시 제안값을 적용하고 표시한다.
3. 캐릭터 색을 배경 색보다 우선하며 카피는 편집 레이어로 분리한다.
4. 출력: 색상표, 폰트, 컷별 레이아웃/모션, 납품 사양, 대비/크롭/권리 검수.

공통: 경로는 프로젝트 루트 기준. 확정 사실과 제안을 구분하며 누락된 자료를 임의 생성하지 않는다.
