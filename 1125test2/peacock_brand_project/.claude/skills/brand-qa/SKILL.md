# brand-qa

1. fixed.md, visual_rules.md, 상품 CSV, 해당 스토리보드와 실제 결과물을 비교한다.
2. 캐릭터 구조·색상·장신구·꼬리·프레임 간 일관성, 카피 근거, 폰트/음원/이미지 권리, 규격·길이·안전영역을 검사한다.
3. 핵심 외형 위반이나 근거 없는 상품 주장은 FAIL, 자료 부족은 NOT_CHECKED. 실제 파일 없이 PASS 판정하지 않는다.
4. 출력: 검사 항목, PASS/FAIL/NOT_CHECKED, 증거, 수정 지시, 최종 승인 여부. 승인 권한은 사용자에게 있다.

공통: 경로는 프로젝트 루트 기준. 확정 사실과 제안을 구분하며 누락된 자료를 임의 생성하지 않는다.
