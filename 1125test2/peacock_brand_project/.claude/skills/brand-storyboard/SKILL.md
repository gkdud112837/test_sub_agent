# brand-storyboard

1. `storyboard_v1.md`, `teaser_plan.md`, 캐릭터/비주얼 규격 및 상품 CSV를 읽는다.
2. 기존 승인 자료를 덮어쓰지 않는다. 변경 요청 시 버전을 올리고 변경점을 기록한다.
3. 컷 ID, 시작/종료 시각, 화면, 모션, 카피, 오디오, 참조 및 QA를 정리한다. 전체 시간 합계를 확인한다.
4. 각 컷 프롬프트에는 캐릭터 고정 프롬프트와 장면 변수를 분리한다. 카피는 후반 합성한다.
5. 출력: 타임라인, 컷별 프롬프트, 편집/사운드 지시, 승인 게이트. 검증되지 않은 상품이나 카피는 제외한다.

공통: 경로는 프로젝트 루트 기준. 확정 사실과 제안을 구분하며 누락된 자료를 임의 생성하지 않는다.
