# 2026-11-25 작업 요약 · 회고 (1125test, 1125test2)

## 1. 배운 내용

**MCP 개념 (1125test)**
- MCP는 AI 앱이 외부 도구와 데이터에 연결하는 방법을 정한 공개 표준임. 흔히 "AI용 USB-C"에 비유함.
- 구성은 세 가지임.
  - 호스트: 사용자가 쓰는 AI 앱
  - 클라이언트: 호스트 안에서 서버와 대화하는 연결 담당
  - 서버: 도구, 리소스, 프롬프트를 표준 형식으로 공개
- 대화 흐름은 `initialize` → `list_tools` → LLM이 도구 선택 → `call_tool` → 최종 답변 순서임. 통로는 stdio 또는 Streamable HTTP임.
- MCP는 function calling과 다름. 어떤 함수를 부를지 고르는 건 모델 기능이고, 그 함수를 어디서 가져와 어떻게 실행하는지가 MCP임. LLM은 서버에 직접 접속하지 않음.
- MCP Python SDK 2.x에서는 `FastMCP`가 `MCPServer`로 바뀌었고, 포트는 `run()`에 넘김. 에러를 `ToolError`로 던져야 LLM이 메시지를 볼 수 있음.
- MCP vs CLI 논쟁의 결론: MCP가 사라지는 중이 아니라 쓰는 방식이 다듬어지는 중임(필요한 도구만 나중에 불러오기, 코드 실행 방식).

**Blender MCP와 3D 프리비즈 (1125test2)**
- Blender MCP가 작동하려면 MCP 서버 등록, Blender 실행과 애드온 활성화(9876 포트), `uvx`가 모두 필요함.
- 세션 도중에 등록한 MCP 서버는 세션을 다시 시작해야 도구로 보임. 그 전에는 애드온 소켓으로 직접 통신하면 됨.
- 공간은 배경 → 건물 → 자연 → 디테일 → 텍스처 순서로 쌓고, 블록아웃이 끝나면 스크린샷으로 확인함.
- 스케일은 처음부터 미터 단위로 잡음. 승인된 원본은 덮어쓰지 않고 v00N으로 버전을 올림.

## 2. 실습 진행 내용과 결과

**1125test: MCP 전후 비교 (AI 경영정보비서)**
- Before는 Gemini tool use로 날씨, 환율, 매출 조회를 파일 하나에 직접 연결함. After는 연결 부분을 MCP 서버(포트 9000)로 분리함.
- 결과:
  - 서비스 코드: 251줄 → 108줄
  - 서비스가 가진 외부 키: 3개 → 1개
  - 손으로 쓴 도구 스키마: 0개(서버가 자동 생성)
  - `# [불편]` 표시: 13곳 → 0곳
- 답변 결과는 그대로였음(매출 합계 129,300,300원).
- 이후 SDK 2.x 기준으로 서버를 보완했고, 해외지사 조회 도구 `get_office`를 추가함. 정리 문서는 `1125test/mcp_before_after/COMPARISON.md`와 `LEARNINGS.md`임.
- 겪은 문제:
  - Gemini 503·504 오류(구글 쪽 용량 부족)
  - 무료 등급 분당 5회 제한
  - 환율 API의 문자열 숫자, JPY(100) 단위, 영업일 처리

**1125test2: Blender MCP로 3D 프리비즈 제작**
- 처음 확인했을 때는 연결이 전혀 안 된 상태였음. uv, Blender 5.3, 애드온을 설치하고 MCP를 등록해서 연결에 성공함(`ping`과 장면 조회 성공).
- **S01 v001:** 티아라 보석 클로즈업 3초 컷임(1080×1920, 30fps, 90프레임, 푸시인과 반사광). 테스트 렌더에서 깨진 보석 면과 하얗게 날아간 색을 찾아 고침.
- **S01 v002:** 카메라를 1.6m 높이에 고정하고, 전신 블록아웃(H=1.30m 가정)과 전신 검토용 카메라를 추가함.
- 결과물(`peacock_brand_project/video/previz/`): `.blend` 파일 2개, 키프레임 스틸, MP4 2개, QA 기록. 정리 문서는 `배운내용.md`, `프롬프트.md`임.

## 3. 수업 회고

**잘된 점**
- 같은 기능을 Before와 After로 나란히 만들어 보니, MCP의 가치가 줄 수가 아니라 연결 코드를 한 곳에 모으고 재사용하는 데 있다는 게 숫자로 보였음.
- 오전에 배운 MCP 구조(서버, 클라이언트, transport)가 오후 Blender MCP 연결 문제를 진단할 때 그대로 쓰였음. 등록, 프로세스, 포트를 하나씩 확인하는 방식이었음.
- 스크린샷으로 검토하는 습관 덕분에 로그만으로는 놓쳤을 문제를 세 번 잡았음.

**아쉬운 점과 개선할 점**
- 요청한 `video/shotlist.md`가 없어서 다른 문서로 대체함. 지시할 때 기준 파일 경로를 확인하고 시작하는 게 좋음.
- v001에서 화면에 보이는 부분만 만들었다가, 카메라 높이 요청이 오자 전신을 다시 만들었음. 처음부터 실제 스케일로 전체 장면을 블록아웃했다면 재작업이 없었을 것임.
- 외부 API(Gemini)의 용량과 사용량 제한은 코드로 해결할 수 없음. 재시도나 대체 모델을 미리 준비해야 함.

**다음에 할 것**
- 세션을 다시 시작해서 `mcp__blender__*` 도구를 직접 쓰는 흐름으로 실습함.
- 꼬리 15깃, 캐릭터 크기 같은 가정값을 승인받고, 티아라와 머리깃을 세부 모델링함.
