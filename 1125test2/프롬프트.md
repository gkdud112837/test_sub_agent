# 1125test2 | Blender MCP 프리비즈 프롬프트 모음

이번 실습에서 실제로 쓴 지시문과 결과 설정값을 다시 쓸 수 있게 정리했다.

## 1. 지시문

### 1-1. 연결 확인 + 장면 조회
```text
블렌더 mcp 연결상태 확인해주고, 현재 블렌더 장면의 오브젝트 목록, 카메라, 렌더 설정을 조회해.
연결이 정상적으로 작동하는지 결과 알려줘.
```

### 1-2. 설치·연결 진행
```text
모두 진행해.   (uv 설치 → Blender 설치 → 애드온 활성화 → claude mcp add blender)
```

### 1-3. 샷 프리비즈 제작
```text
블렌더 mcp를 사용해서 video/shotlist.md의 s1장면을 3d프리비즈로 제작해줘
```
보완 팁: 기준 문서 경로를 정확히 적는다. 이번에는 `video/shotlist.md`가 없어서 `storyboard_v1.md`의 S01을 대신 썼다.

### 1-4. 카메라 + 전신 블록아웃
```text
현재 블렌더 블록아웃 장면에서 카메라를 설정해줘. 카메라 높이는 1.6m정도.
그리고 몸통은 왜 재현안했어?
```

### 1-5. 공간 구성 + 스크린샷 검토 (다음 실습용 템플릿)
```text
[장면 ID]를 블렌더 MCP로 블록아웃해줘.
- 공간 구성 순서: 배경 → 건물/구조물 → 자연·주변 요소 → 디테일 → 텍스처/재질
- 단위는 미터. 캐릭터 크기 H=[값]m (모르면 가정값으로 두고 '추정'으로 표시)
- 카메라: 높이 [1.6]m, 렌즈 [mm], 타깃 [오브젝트]
- 블록아웃이 끝나면 장면 스크린샷(테스트 렌더 또는 뷰포트)을 보여주고 문제점부터 보고해.
- 기존 버전 파일은 덮어쓰지 말고 v00N으로 저장해.
```

## 2. 카메라 설정 (v002 기준)

| 항목 | CAM_S01 (S01 렌더용) | CAM_REVIEW_WIDE_1p6m (전신 검토용) |
|---|---|---|
| 높이 | 1.60m 고정 | 1.60m |
| 렌즈 | 200mm (센서 36mm, Auto fit) | 45mm |
| 조리개(DOF) | f/5.6, 초점 = 중앙 보석 | f/8 |
| 타깃 | Track To → 보석 위치 (0, -0.18, 1.27) | Track To → (0, 0, 0.80) |
| 움직임 | 수평 거리 1.25m(f1) → 0.95m(f90) 푸시인 | 고정, y = -4.2m |
| 내려다보는 각도 | 14.8° → 19.2° | 약 11° |

조명:
- 기본 3점 조명: 소프트 키(웜 `#FFF0E5`, 260W), 필(핑크 `#FFD0D9`, 90W), 림(골드 `#FFE6A3`, 300W)
- 반사광: `LIGHT_glint_moving` 작은 면광원(0.02m, 5W)이 보석 앞을 좌→우로 이동
